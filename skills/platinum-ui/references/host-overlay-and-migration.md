# 存量现代 SaaS / 第三方宿主换肤与宏观窗口化指南

当目标不是从零编写 HTML/JSX，而是给既有现代 Web 应用或第三方宿主（如浏览器扩展注入、外部客户端主题插件、不能硬编码 CSS Module 哈希类名的叠加层）套用 **Mac OS 9 Platinum** 外观时，**「只换灰底 + 给两三个按钮加斜面」远远不够**——界面仍会像现代扁平 SaaS。本手册界定宏观骨架改造方法、与宿主业务的职责边界及真机验收门禁。

## 1. 宏观窗口化四层骨架映射（必先定骨架，再修按钮）

换肤现代多栏工作台（如“左侧导航栏 + 顶部标题/页签栏 + 白底正文/对话区 + 底部输入条”）时，按自外向内四层映射物理深度：

| 现代扁平 SaaS 区域 | Platinum 物理角色 | 纯 CSS 宿主换肤做法（零改 DOM） |
|---|---|---|
| 整页底色 / 多栏间隙 | **桌面画布（`--pt-canvas`）** | 两种可选强度：① **全桌面窗口化**：外层容器给 `--pt-canvas` 背景 + `8px–12px` 内缩，让侧栏与主工作区各自呈现 `1px` 黑框与 `2px` 硬投影；② **克制机械工作台**（高密度代码/聊天工具优先保视野）：贴边铺满，但用 `1px solid var(--pt-frame)` 实线与 `--pt-bevel-window` 明确切分每个窗格 |
| 顶部导航 / 会话标题栏 | **窗口标题栏（`22px` 横纹或凸起金属工具条）** | 无专属标题栏 DOM 时，可通过主工作区或弹窗顶部的 `::before` 伪元素绘制居中 `12px` 六条细横纹（并给滚动区加 `scroll-padding-top`），或将顶栏改造为 `--pt-face` + `--pt-bevel-strip` + `1px solid var(--pt-frame)` 金属工具栏 |
| 现代下划线 Tab（如 `对话 \| 轨迹`） | **立体选项卡 / 连体分段组** | 去掉细下划线指示器，将当前页签改为压下深炭底（`--pt-pressed-bg` + `--pt-bevel-pressed`）或接入白井的实体凸起折页签 |
| 正文流 / 表格 / 代码区 / 输入框 | **下凹内容井（`--pt-paper` + `--pt-bevel-sunken`）** | 长文与表格区置入有框白井（并强制补齐 `th, td` 首尾列 `padding: 6px 10px` 防贴边；注意 `dist/platinum.css` 规则位于 `@layer pt.*`，覆盖未分层的宿主 Markdown 样式时该条须写在层外）；底部输入区与状态栏做成带 `--pt-window` 托盘或 `--pt-bevel-strip` 工具条的独立下凹输入坞，避免大片纯白里漂浮一根生硬黑框 |

## 2. 控件覆写分级：避免“漏改圆形钮”与“满屏黑框过噪”

存量现代界面通常包含几十个按钮，切忌“一刀切全加粗黑框”或“只改两三个显眼按钮”两种极端：

1. **必须强立体化（常驻 `1px` 实框 + 斜面）**：
   - 主操作与发送按钮（严禁保留 `border-radius: 50%` 圆形蓝/紫底，改为 `2px/3px` 实体方钮或 HIG 双黑环默认钮）；
   - 悬浮回底/跳转按钮（如圆形 `↓` FAB，必须去圆形改为 `26×26px` 实体方形斜面钮）；
   - 顶栏主切换钮、侧栏新建/主动作钮、弹窗确认/取消钮、原生及自绘 `<select>`、`[role="switch"]`。
2. **克制浮现斜面（静息扁平，悬停/激活浮现 `--pt-bevel-mini`）**：
   - 高频低权重图标按钮（如每条消息旁的复制/点赞图标、侧栏行内操作图标、输入框内 `+` 附件钮），静息保持干净无框，悬停时浮现 `1px` 轻框与 `--pt-bevel-mini`，既维持 Platinum 触感又不让满屏布满黑色噪点。
3. **绝对禁止套 3D 框的元素**：
   - 按钮、菜单项与 Tooltip 内部的 `<kbd>` 快捷键提示（必须保持无框等宽平字，禁止出现按钮里套 3D 键帽把文案撞穿的情况）；
   - `input[type="radio"]`（保留正圆，其余控件一律遵守 `0px / 2px / 3px` 圆角纪律）。

## 3. 规范库 vs 宿主项目的职责边界

| 归属 | 负责内容 |
|---|---|
| **`platinum-ui` 通用规范** | 中性色阶与 AA 对比度、四层物理深度语法、跨平台窗控、通用反模式（斜面遮挡、`kbd` 碰撞、表格贴边、去圆角）以及通用静态/Chromium 残余扫描探针 |
| **具体宿主适配层** | 决定“全桌面留白”还是“贴边高密度工作台”；选择稳定 DOM 锚点（零哈希类名约束下的 `data-*` / ARIA / 结构选择器取舍）；映射宿主独有复合组件（思考折叠块、轨迹图、模型选择器、代码高亮变量表与插件卸载生命周期） |

## 4. 宿主换肤交付前的真机目视验收门（不可仅凭合成夹具过关）

在第三方宿主换肤场景下，除静态扫描与单测外，**必须对真实运行中的目标页面（非手拼静态 mock）执行以下 5 项核验**：

1. **自动化残余扫描**：在真实运行页面注入并执行 `platinum-check.mjs` 导出的 `ICON_BUTTON_PROBE_SOURCE` + `findIconButtonIssues`，确认 0 圆角/胶囊泄漏（`border-radius >= 8px`）、0 表格单元格贴边（`padding-inline < 6px`）、0 按钮内 `<kbd>` 3D 盒或重叠溢出、0 图标偏心与热区不足；
2. **宏观窗口层级目视**：截全屏图核对亮/暗双模，确认页面呈现清晰的金属底盘、顶栏/工具条与下凹内容井层级，不再是“白底黑线扁平 SaaS”；
3. **悬停与激活态实测**：悬停带快捷键提示的主按钮、弹出菜单与下拉框，确认无快捷键撞字、无反白文字对比度失效、悬停不抹掉已激活深炭态；
4. **长文与表格实测**：在含 Markdown 表格与代码块的页面确认首尾列文字不贴边、代码块标题条与复制钮比例协调；
5. **可逆卸载实测**（如为插件主题）：关闭/卸载主题后检查页面零残留样式与属性。
