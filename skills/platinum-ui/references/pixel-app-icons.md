# 16×16 整数像素应用图标设计规范

提炼自跨平台（`.ico` / `.icns` / `.png`）Platinum 桌面图标实战，解决小尺寸任务栏/扩展栏缩略模糊问题。

## 1. 核心约束：先过 `16×16` 整数像素关

- 在 Windows 任务栏、系统托盘与浏览器扩展工具栏中，图标常以 `16×16px`（扣除 `2px` 外留白与边框后，内部有效画布仅 **`12×12px`**）渲染。
- **严禁直接把复杂多窗格插画或细线矢量图等比缩小到 `16×16`**：亚像素抗锯齿会把细节糊成一团灰噪点。

## 2. 分档绘制策略

| 尺寸档位 | 绘制原则 |
|---|---|
| `16×16` / `24×24` / `32×32` | **手工对齐整数像素网格（Pixel-Grid Snapped）**：外框固定落在整数坐标 `1px` 实线（`#262626`），内侧左上 `1px` `#ffffff` 高光、右下 `1px` `#808080` 暗边；内部图形或字母使用 `3×5` 或 `5×7` 点阵字模，关闭亚像素半透明羽化。 |
| `48×48` / `64×64` / `128×128` | 整数倍放大点阵骨架（`2×` / `4×` / `8×` nearest-neighbor 或整倍数 SVG `shape-rendering="crispEdges"`），可补入 `2px` 硬边投影（`#262626`）与经典 Platinum 斜面高光层次。 |
| `256×256` / `512×512` / `1024×1024` | macOS `.icns` 留出外围约 `10%` 安全内边距，保持直边/微切角立体徽章造型，不混入现代弥散发光阴影。 |

## 3. 交付验收三查

1. 将导出图在 `100%` 缩放下按 `16px`、`32px`、`128px` 并排贴在浅色（`#cccccc`）与深色（`#181818`）双底板上目视检查：深色底板下若 `#262626` 外框融入背景，须确认内侧 `1px` 高光边或浅底主体足以撑起轮廓。
2. 打包 `.ico` 时显式内嵌 `16, 24, 32, 48, 64, 128, 256` 多图层（不要只塞一张 `256×256` 让系统双线性插值缩小）。
3. 纯工具脚本生成图标时校验输出 PNG 无意外裁剪、透明通道干净。
