# 在原有布局上更换 Platinum 材质

适用于用户明确要求保留布局和控件尺寸的换肤。先选定视口、缩放、明暗模式和界面状态，再用同一条件切换主题，对照三项结果。

1. **可见边界。** 记录分区、控件及相邻元素的位置和尺寸。保留字体度量、换行与断点，在原有表面绘制金属边沿、按钮斜面和内容井。若绘制面与可点击元素大小不同，用截图核对可见边框，用 DOM 矩形核对布局占位。
2. **真实命中。** 从可见控件向无人操作的空白扩展热区。例如原生提交钮高 21px，上边贴着输入框而下边空出 3px，可加 3px 透明下边框，以等量负下边距维持行高，把背景、斜面与文字留在原来 21px 内。核对基线及焦点边框。原生提交钮上的伪元素是否接到指针，要在目标浏览器实测。
3. **相邻操作。** 用 `document.elementFromPoint(x, y)` 在连续 24×24 CSS 像素内逐点取中心，核对命中元素或其关联控件。用真实指针点击扩展区、输入框下沿及相邻按钮靠近边界的一侧，检查各自的焦点或提交结果。复测键盘操作及关掉主题后的恢复。交付时分列可见几何、有效热区与相邻操作。空白不足或无法实测时，保留原几何并注明短缺或未验证的项目。
